**Leonida Platinum Companion** is an offline GTA VI trophy guide & tracker. It covers all **55 trophies** from the official PlayStation list — name, description and grade exactly as published — and pairs each one with an original guide written in our own words, with its sources cited on the card.

- **Platinum roadmap** — the 55 trophies arranged into six staged phases, from story-first chapters through the long grinds to the platinum itself, with inferred watch-list flags clearly labelled (no confirmed missables are claimed).
- **Spoiler mode** — secret trophies stay masked (name, description and guide hidden) until you have earned them.
- **Tracker** — tick trophies off into a localStorage checklist with per-grade counters and a progress bar, and move your progress between devices with JSON export/import.
- **Fully offline** — plain static files, no build step, nothing fetched from the network. Open `app/index.html` in a desktop browser and it just works.

## Run it

```
node main.ts
```

That copies `app/` and `screenshots/` to the output directory and writes the entry's `dossier.json`. To try the guide locally instead, run `node serve.ts` and open http://localhost:8080.
