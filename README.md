**Leonida Platinum Companion** — an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. All 55 official trophies with their published names, descriptions and grades; an own-words guide for every trophy with its sources named on the card; a six-stage roadmap to the platinum built from the official descriptions, with fact and inference kept apart (no confirmed missables — two INFERRED watch-list flags, labelled as inference); a spoiler shield that masks secret trophies until earned; and a checklist that saves in the browser and exports/imports as a file. Warm-paper editorial design, vanilla JavaScript, no build step, no network.

The data file `app/data/trophies.json` is generated by `tools/build-data.mjs` from the official list, the official secret flags and the entry's own curation in `tools/curation.mjs` — regenerate it rather than editing it by hand.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080
node --test tests/logic.test.mjs   # 7 contract tests
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # hand-in: writes out/ + dossier.json
```
